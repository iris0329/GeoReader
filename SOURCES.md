# Data sources

Use the prepared [GeoReader-MindCube](https://huggingface.co/datasets/RRRong/GeoReader-MindCube)
and [GeoReader-MultiSource](https://huggingface.co/datasets/RRRong/GeoReader-MultiSource)
packages for the released training and evaluation recipes. Download and extraction
commands are in the [README](README.md).

The links below point to upstream datasets, annotations and benchmark releases.

## Images, videos and geometry

- **ScanNet:** [official site](https://www.scan-net.org/ScanNet/) and
  [download tools](https://github.com/ScanNet/ScanNet).
  See the [Stage 1 download guide](data_preparation/stage1/scannet.md).
- **ScanNet++:** [official portal](https://scannetpp.mlsg.cit.tum.de/scannetpp/)
  and [documentation](https://scannetpp.mlsg.cit.tum.de/scannetpp/documentation).
  See the [Stage 1 download guide](data_preparation/stage1/scannetpp.md).
- **ARKitScenes:** [official repository and downloads](https://github.com/apple-aiml-research/ARKitScenes).
- **Matterport3D:** [official project and download access](https://niessner.github.io/Matterport/).
- **DTU:** [official MVS dataset downloads](https://roboimagedata.compute.dtu.dk/?page_id=36).
- **AgiBotWorld:** [official dataset](https://huggingface.co/datasets/agibot-world/AgiBotWorld2026).
- **nuImages:** [official dataset portal](https://www.nuscenes.org/nuimages).
- **nuScenes:** [official dataset portal](https://www.nuscenes.org/).
- **SUN RGB-D:** [official project and downloads](https://rgbd.cs.princeton.edu/).
- **DAVIS:** [official downloads](https://davischallenge.org/davis2017/code.html).
- **TAP-Vid:** [official annotations and tools](https://github.com/google-deepmind/tapnet).
- **EgoDex:** [official repository and downloads](https://github.com/apple-aiml-research/ml-egodex).
- **EPIC-Contact:** [dataset and source-video instructions](https://huggingface.co/datasets/Sid2697/epic-contact/blob/main/DATASET.md).
- **COCO:** [official downloads](https://cocodataset.org/#download).
- **RefCOCO+:** [official annotation API and downloads](https://github.com/lichengunc/refer).
- **EmbodiedScan:** [official annotation downloads](https://github.com/InternRobotics/EmbodiedScan/blob/main/data/README.md).
- **Omni3D:** [official annotations and source-data instructions](https://github.com/facebookresearch/omni3d/blob/main/DATA.md).

- **MindCube:** [official repository](https://github.com/mll-lab-nu/MindCube)
  and [dataset](https://huggingface.co/datasets/MLL-Lab/MindCube).
- **SpatialLadder:** [official repository](https://github.com/ZJU-REAL/SpatialLadder)
  and [training QA](https://huggingface.co/datasets/hongxingli/SpatialLadder-26k).
- **SPAR:** [official repository](https://github.com/LogosIntelligenceLab/SPAR)

- **Spatial-MM:** [official repository and dataset links](https://github.com/FatemehShiri/Spatial-MM).

  and [released annotations](https://huggingface.co/datasets/Journey9ni/VLM-3R-DATA).
